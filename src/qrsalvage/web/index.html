Common situations


    

      My QR code won't scan — can anything still read it?
      
Often, yes. A reader app needs the whole code to be clean; qrsalvage instead treats
      the parts every QR code must contain as a calibration target, measures how damaged the
      rest is, and uses the code's own error correction to reconstruct what is missing. It can
      recover some codes that ordinary scanner apps reject — and tells you honestly when too
      much is physically gone.

    


    

      Does it matter what the QR code belongs to or what it contains?
      
No. Recovery works from the QR structure, not from an assumed product or use case. The
      code may be on packaging, a ticket, a document, a sign, an inventory tag or a device. Its
      payload may be a web address, contact card, email, phone number, location, Wi-Fi login,
      pairing code or plain text. Recognised formats are labelled after recovery; unknown content
      stays plain text rather than being guessed.

    


    

      The QR code is on a curved bottle, tube, tool or device
      
A code wrapped around a curved object defeats normal
      readers because straight grid lines become curves; qrsalvage fits a bowed grid to the
      surface before reading a single cell. Take several photographs from slightly different
      angles — what the curvature hides in one, another still shows, and they are read
      together.

    


    

      Zigbee install code or Matter pairing code unreadable
      
For this specific kind of engraved or printed device label, recovery does more than
      return a string: it recognises a Zigbee install code, a Matter onboarding
      code, Wi-Fi credentials — and shows the fields you actually need to type into your hub,
      including the 11-digit Matter manual pairing code. A pairing code is a secret: it never
      leaves your device here, and be careful where else you paste it.

    


    

      The code is engraved in metal or plastic, scratched or faded — barely any
      contrast
      
Laser engraving and wear defeat readers because dark and light modules become nearly
      the same shade. qrsalvage estimates the two brightness levels from the parts of the code
      whose values are fixed by the standard, then scores every other cell against them — so
      even a few percent of contrast, spread unevenly across the label, can be enough. The
      method page shows this step by step, with real figures.

    


    

      A tiny label on a product, component or device that no app will scan
      
Those labels are tiny, and the physics is unforgiving: once a module of the code is
      smaller than about five pixels in your photograph, or the photo is so blurry that
      neighbouring modules smear into each other, recovery becomes unlikely. In the synthetic
      resolution benchmark the rate collapses between five and four pixels per module; that is
      practical guidance, not a universal cutoff. The fix is in the photograph, not the app —
      get as close as your camera focuses, fill the frame with the label, and take several shots
      from slightly different angles. This tool fuses them, and the measured gain from fusion is
      larger than from any other step.

    


    

      The label is torn, or the print has partly worn away
      
Missing is better than wrong. A QR code carries error correction that repairs twice as
      many known-missing cells as misread ones, so qrsalvage marks what it cannot trust
      as unknown instead of guessing — worn print becomes exactly the kind of damage the code
      was designed to survive. A torn edge that bends the paper is handled too: the grid is
      re-fitted before cells near the tear are read.

    


    

      Can I read a QR code from a photo without uploading it anywhere?
      
Here, yes — and verifiably so. The entire recovery runs inside your browser; there is
      no server that could receive your photograph, and the page's own security policy forbids
      it from talking to one. That matters for private documents, tickets, contact details,
      network credentials and pairing secrets. The first visit downloads the recovery engine (about 29 MB,
      then cached), which is the honest price of nothing leaving your device.

    


    

      What if the code really is beyond saving?
      
Then qrsalvage says so, and says why: it distinguishes a code it cannot find
      from one whose data area is physically destroyed beyond what error correction can carry.
      If several photographs agree the grid is clean but too many modules are simply gone, no
      tool can recover it — and knowing that is worth more than a spinner that never ends.

    

  


  
  

    
Häufige Fragen (deutsch)


    

      Der QR-Code lässt sich nicht scannen — was kann ich noch tun?
      
Oft eine ganze Menge. Eine Scanner-App braucht den ganzen Code in sauber; dieses
      Werkzeug nimmt die Teile, die jeder QR-Code enthalten muss, als Eichmaß, misst daran die
      Beschädigung und rekonstruiert den Rest über die eingebaute Fehlerkorrektur des Codes.
      Es liest deutlich über den Punkt hinaus, an dem Handykameras aufgeben — und sagt ehrlich,
      wenn zu viel physisch zerstört ist. Alles läuft in Ihrem Browser, das Foto wird nirgendwo
      hochgeladen.

    


    

      Spielt es eine Rolle, wozu der QR-Code gehört oder was er enthält?
      
Nein. Die Rekonstruktion arbeitet mit der Struktur des QR-Codes, nicht mit einer
      Vermutung über sein Produkt oder seinen Zweck. Der Code kann auf einer Verpackung, einem
      Ticket, Dokument, Schild, Inventaretikett oder Gerät stehen. Erkannte Formate werden erst
      nach der Rettung benannt; unbekannter Inhalt bleibt Klartext, statt erraten zu werden.

    


    

      Der Code sitzt auf einer gewölbten Flasche, einem Rohr oder Gerät
      
Genau so ein Fall ist der Grund, warum es dieses Werkzeug gibt. Auf einer Wölbung
      werden aus geraden Gitterlinien Kurven, daran scheitern normale Leser; hier wird ein
      gebogenes Gitter an die Fläche angepasst, bevor eine einzige Zelle gelesen wird. Machen
      Sie mehrere Fotos aus leicht verschiedenen Winkeln — was die Wölbung im einen verbirgt,
      zeigt das andere, und alle werden gemeinsam gelesen.

    


    

      Zigbee-Install-Code oder Matter-Pairing-Code unlesbar
      
Bei genau dieser Art gravierter oder gedruckter Geräte-Etiketten liefert das Werkzeug
      mehr als eine Zeichenfolge: Es erkennt Zigbee-Install-Code,
      Matter-Code, WLAN-Zugang — und zeigt die Felder, die Sie in Ihren Hub eintippen müssen,
      inklusive des elfstelligen manuellen Matter-Codes. Ein Pairing-Code ist ein Geheimnis:
      Er verlässt Ihr Gerät hier nicht, und Vorsicht, wo Sie ihn sonst einfügen.

    


    

      Muss ich das Foto irgendwohin hochladen?
      
Nein — und das ist nachprüfbar. Die gesamte Rekonstruktion läuft in Ihrem Browser; es
      gibt keinen Server, der Fotos entgegennehmen könnte, und die Sicherheitsrichtlinie der
      Seite verbietet ihr, mit einem zu sprechen. Beim ersten Besuch lädt der Browser die
      Rechenumgebung (rund 29 MB, danach im Cache) — das ist der ehrliche Preis dafür,
      dass nichts Ihr Gerät verlässt.

Private by construction, open by default

    
Every QR code can carry something different. Recovery runs entirely on this device;
      photographs and recovered text are never uploaded, and the same-origin security policy
      prevents the application from sending them elsewhere.
